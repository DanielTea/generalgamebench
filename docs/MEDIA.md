# Environment media

These are real gameplay captures and credited project or publisher previews. No game screenshot was generated by AI. The catalog contains 26 validated environment cards (33 scenarios) and 19 unadmitted candidates; a preview does not establish an implemented adapter or benchmark result.

Original code is MIT licensed. Third-party game artwork, screenshots, recordings and trademarks retain their respective rights and are excluded from that license; consult each source before reuse. Rehosting a preview grants no game or asset license.

Every validated card shows a still and a four-second clip of consecutive recorded benchmark frames at 6 frames per second. Previews use the longest published random-control episode per pictured task, breaking ties by the lowest seed. MiniWorld instead shows seed 4001, where the red goal box is visible. These display choices do not affect rankings. ViZDoom shows the basic task and lists all eight validated scenarios. Other clips are short excerpts of upstream demonstrations. Playback speed is illustrative, not evidence of model latency. GIF previews start and stop only when selected; MP4 copies are available to download from each clip’s details. Only one preview plays at a time. Candidates without a local clip link to credited project media or official trailers; a media link never changes integration status.

The source manifest records original asset URLs, credits and image hashes: [sources.json](../site/dist/media/sources.json). The README collage includes every catalog card.

## Rebuild recorded previews

Extract the v0.2.0 evidence archive at the repository root, install FFmpeg, then run `uv run python scripts/build_card_media.py` and `uv run python scripts/build_atlas.py`. The media builder validates each selected ledger and frame hash against the published evidence roots. It invokes no model or game engine. The source manifest includes the selected episode, evidence root, playback rate and generated asset hashes. The historical score snapshot stays unchanged.
