# Environment media

These are real gameplay captures and credited project or publisher previews. No game screenshot was generated by AI. The catalog contains 3 runnable environment cards (10 scenarios) and 42 research candidates; a preview does not establish an implemented adapter or benchmark result.

Original code is MIT licensed. Third-party game artwork, screenshots, recordings and trademarks retain their respective rights and are excluded from that license; consult each source before reuse. Rehosting a preview grants no game or asset license.

Local clips show consecutive recorded benchmark frames at 12 frames per second. Other clips are short excerpts of upstream demonstrations. Playback speed is illustrative, not evidence of model latency. GIF previews start and stop only when selected; MP4 copies are available to download from each clip’s details. Only one preview plays at a time.

The source manifest records original asset URLs, credits and image hashes: [sources.json](../site/dist/media/sources.json). The README collage includes every catalog card.
