# Game integration coverage

Reviewed 2026-10-04. **33 runnable scenarios across 26 catalog cards; 19 cards remain unadmitted.** The 45 cards include game families, not 45 fully implemented unique games. No modern commercial AAA title is admitted yet.

All 23 newly admitted optional tasks passed real engine, legal-action, termination and exact frame/score replay checks on this Apple M3 Max Mac. Together with the original 10 scenarios they form the expanded suite. See [installation and precise task definitions](../environments/README.md).

## Remaining work

SuperTuxKart has a working experimental adapter and a failing pixel-replay gate. It is deliberately excluded. Luanti, Veloren, Warzone 2100, 0 A.D., SuperTux, Mindustry, OpenTTD, Dungeon Crawl Stone Soup and Cataclysm DDA still need game-specific visual control, reset, referee scoring and replay adapters. Available source code does not make those integrations complete.

Unity has a pinned Mac executable and experimental camera adapter; full goal/scoring validation and referee admission remain unfinished. See [actual integration attempts](INTEGRATION_ATTEMPTS.md). Google Research Football needs a compatible rendered runtime on this Mac. Minecraft, StarCraft II, Rocket League, Factorio, Cyberpunk 2077, Morrowind/OpenMW and Half-Life 2 additionally need their specific local installations/assets and compatible execution setups; they were not available as runnable test installations here. RocketSim must be labeled separately from retail Rocket League.

Admission requires documented controls, independently extracted rewards, fixed reset/seed policy, engine and asset versions, native termination, exact evidence checks, and a permitted offline execution setup. Asset installations and proprietary ROMs are never committed. Production hostile-agent execution remains separate from these trusted local tests.
